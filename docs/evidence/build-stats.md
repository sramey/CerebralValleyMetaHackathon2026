## What this does not measure

- Only this machine's log window. Earlier sessions are in the same file; nothing was hand-tuned or removed.
- Prompt quality, art quality, or how a person felt about the result: those need a human watching the demo.
- Live-demo timings on the judge's network; latency here is a local build loop against the real API.
